# 知识体系数据格式（KA.json）

定义 `<课程名>-KA.json` 的知识体系数据结构，供 `/knowledge` 命令生成、以及后续题库建设命令读取时统一遵守。

## 文件

- 路径：`.harness/data/<课程名>-KA.json`
- 文件名中的课程名与 `courses.json` 中的「名称」保持一致（中文原名）

## 结构

```json
{
  "课程名称": "智能软件工程",
  "课程描述": "讲授传统软件工程的发展和过程知识、过程、方法、工具和范型……",
  "知识体系": [
    {
      "领域": "软件过程",
      "知识点": ["需求工程", "软件设计", "软件测试"]
    }
  ],
  "更新时间": "2026-08-15 10:30:00",
  "完整性评分": 92
}
```

## 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `课程名称` | string | 是 | 与 courses.json 中的「名称」一致 |
| `课程描述` | string | 是 | 取自 courses.json 的「描述」 |
| `知识体系` | array | 是 | 二级结构：每个元素是一级「领域」，内含「知识点」数组 |
| `领域` | string | 是 | 一级知识领域（名词/短语） |
| `知识点` | array | 是 | 该领域下的二级知识点（名词/短语） |
| `更新时间` | string | 是 | `yyyy-MM-dd hh:mm:ss` 格式（本地时间） |
| `完整性评分` | number | 否 | 0–100，稳定性量化指标 |

## 约束

- 「领域」和「知识点」必须是名词或短语，不能是句子，不能带补充说明，最好不要有标点符号
- 二级结构：每个「领域」下挂若干「知识点」，知识点不跨领域重复
