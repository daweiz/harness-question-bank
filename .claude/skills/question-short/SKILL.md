# /question-short 简答题

生成符合排版规范的简答题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「简答题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：明确要求，如「简述……」「说明……的步骤」「比较……」等，无编号、无引导
- 答案：要点化参考（分条列出），便于人工判分
- 评分标准：答案分多条要点时，在答案之后给出「评分标准」独立部分（满分、各要点分值、给分/扣分要求，分条或表格），用 `---` 分隔
- 难度可涉及理解、应用、分析等更高认知目标，默认难度 3
- 需要图形时生成 svg 插入；表格用标准 Markdown 表格；公式用 LaTeX（行内 `$...$`、独立 `$$...$$`）
