# /question-concept 概念题

生成符合排版规范的概念题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「概念题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：给出概念名称、名词或现象，要求解释定义、说明内涵或辨析相关概念，如「请解释什么是软件危机」「辨析黑盒测试与白盒测试」，无编号、无引导
- 答案：先给核心定义，再分条给出要点；涉及易混概念时可附标准 Markdown 对比表格
- 评分标准：在答案之后给出「评分标准」独立部分（定义、内涵、辨析分别赋分，含满分与给分/扣分要求），用 `---` 分隔
- 解析：补充判断依据或易错点（可选）
- 概念选取应贴合知识点，避免超纲
- 难度贴合一至三级认知目标（识记/理解/辨析），默认难度 3
- 需要概念关系、层次结构图时生成 svg 插入；公式用 LaTeX（行内 `$...$`、独立 `$$...$$`）
