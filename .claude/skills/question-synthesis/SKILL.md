# /question-synthesis 综合题

生成符合排版规范的综合题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「综合题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：给出跨知识点的综合场景，明确要求综合多个知识点分析与解决，如「结合需求工程与软件测试，分析某项目质量问题并提出改进方案」，无编号、无引导
- 答案：按步骤给出综合分析（明确调用到的各知识点 → 分步推理 → 结论/方案），分条列出，可含对比表格、结构图 svg、公式
- 场景应真实，覆盖至少两个相关知识点，分析有层次、结论可落地
- 综合题**应**在场景与知识点之间建立显式联系，避免拼盘式堆砌
- 评分标准：在答案之后给出「评分标准」独立部分，按「知识点调用、分步推理、结论/方案」分项赋分，含满分与给分/扣分要求，用 `---` 分隔
- 难度涉及分析、综合、评价等较高认知目标，默认难度 5
- 需要结构图、对比表时立即生成（svg 优先），图片存入同级 `images/`，md 内以 `images/xxx.xxx` 引用，不留占位符
