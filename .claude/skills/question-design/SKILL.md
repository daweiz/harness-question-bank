# /question-design 设计题

生成符合排版规范的设计题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「设计题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：给出设计任务场景、目标与约束，如「为某系统设计分层架构」「给出实现……的类图设计」，无编号、无引导
- 答案：结构化设计方案，通常包含：设计目标 → 总体结构（svg 图）→ 模块/组件职责（表格）→ 关键设计决策 → 必要的伪代码或接口说明，分条列出
- 设计题**应**生成结构图（架构图、类图、流程图、ER 图等），svg 优先，图片存入同级 `images/`，md 内以 `images/xxx.xxx` 引用，立即生成不占位
- 方案要可行、有取舍依据，符合知识点要求，避免泛泛而谈
- 评分标准：在答案之后给出「评分标准」独立部分，按方案要素赋分（结构图、职责表、关键决策、接口/伪代码），含满分与给分/扣分要求，用 `---` 分隔
- 难度可涉及理解、应用、分析、设计等较高认知目标，默认难度 4
- 表格用标准 Markdown 表格；公式用 LaTeX（行内 `$...$`、独立 `$$...$$`）
