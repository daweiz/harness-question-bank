# /question-fill 填空题

生成符合排版规范的填空题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「填空题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：留空的完整陈述，空位用 `____` 标出，无编号、无引导
- 答案：填空内容，写入「答案」部分；多个空时答案用「；」分隔，与空位顺序一致
- 空位所填内容应唯一、明确，避免多种答案均可的情形
- 通常每空 1–2 个词或一个短短语，难度贴合一至三级认知目标
- 需要图形时生成 svg 插入（如标注图、示意图留空）；公式用 LaTeX（行内 `$...$`、独立 `$$...$$`）
