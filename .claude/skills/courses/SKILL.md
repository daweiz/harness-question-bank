# /courses 课程管理

管理多课程题库建设系统中的课程，提供课程的增删改查（CRUD）操作。

## 数据文件

- 路径：`.harness/data/courses.json`
- 结构：`{ "courses": [ ... ] }`，每门课程是一个对象
- 文件不存在时，创建初始结构 `{ "courses": [] }`
- **不要**为所创建的课程生成或管理知识体系文件（`<课程名>-KA.json`）

## 数据结构

每门课程对象字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 课程唯一标识（UUID） |
| `名称` | string | 是 | 课程名称（全局唯一） |
| `描述` | string | 否 | 课程描述/说明，可省略 |
| `创建时间` | string | 是 | `yyyy-MM-dd hh:mm:ss` 格式（本地时间） |
| `更新时间` | string | 是 | `yyyy-MM-dd hh:mm:ss` 格式（本地时间） |

示例：

```json
{
  "courses": [
    {
      "id": "3f2a9b1c-7d4e-4f5a-9b6c-2e8d1a0b3c4f",
      "名称": "数据结构",
      "描述": "计算机科学核心基础课程",
      "创建时间": "2026-08-14 10:00:00",
      "更新时间": "2026-08-14 10:00:00"
    }
  ]
}
```

## 操作

根据用户输入识别操作类型（支持中文同义动词）：

### 1. 列出课程

- 触发：无参数，或「list / 列表 / 查看全部」
- 行为：读取 `courses.json`，以表格列出所有课程的 名称、描述、创建时间、更新时间
- 无课程时提示「暂无课程」

### 2. 新增课程

- 触发：「create / 新增 / 创建 / 添加」+ 课程名称 [描述]
- 必填：课程名称；可选：课程描述
- 校验：
  - 课程名称为空 → 提示必须提供课程名称
  - 课程名称已存在 → 提示已存在，不重复创建
- 行为：生成 UUID 作为 `id`，记录 `创建时间` 与 `更新时间`（当前时间，格式 `yyyy-MM-dd hh:mm:ss`），追加到 `courses` 数组并写回文件
- 完成后输出新增课程的完整信息

### 3. 查看课程

- 触发：「read / get / 查看 / 查询」+ 课程名称
- 行为：按名称查找，输出该课程的完整信息（含 `id`）
- 未找到 → 提示「课程不存在」

### 4. 更新课程

- 触发：「update / 修改 / 更新 / 编辑」+ 课程名称
- 行为：可修改名称和/或描述
  - 修改名称时校验新名称不与其他课程冲突
  - 更新 `更新时间` 字段
- 未找到 → 提示「课程不存在」

### 5. 删除课程

- 触发：「delete / 删除 / 移除」+ 课程名称
- 行为：删除前向用户确认；确认后从 `courses` 数组移除并写回
- 未找到 → 提示「课程不存在」

## 约束

- 课程名称在 `courses.json` 内必须唯一
- 时间统一使用 `yyyy-MM-dd hh:mm:ss` 格式（24 小时制，本地时间）
- 所有读写均针对 `.harness/data/courses.json`，不涉及其他文件
- 不生成、不管理课程的知识体系文件（`<课程名>-KA.json`）
