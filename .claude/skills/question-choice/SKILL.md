# /question-choice 单选题

生成符合排版规范的单选题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「单选题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：简洁明确，无编号、无引导，用陈述或提问方式给出
- 选项：4 个（A/B/C/D），长度相近；干扰项真实且有迷惑性（常见误解、相近概念、易混淆表述）
- 答案：唯一正确，写入「答案」部分
- 解析：说明正确项依据与干扰项排除理由
- 难度贴合一至三级认知目标（识记/理解/应用），默认难度 3
- 需要图形时生成 svg 插入（如示意电路、流程图、数据结构等）；公式用 LaTeX（行内 `$...$`、独立 `$$...$$`）
