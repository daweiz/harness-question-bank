# /knowledge 知识体系

根据指定课程名称生成并维护二级知识体系（一级知识领域、二级知识点），为后续题库建设提供数据支撑。

## 数据文件

- 课程数据：`.harness/data/courses.json`（只读，作为输入）
- 知识体系：`.harness/data/<课程名>-KA.json`（读写，作为输出）
  - 文件不存在时，按「数据结构」从零创建
  - 已存在时，读取现有内容，在其基础上**丰富完善**，而非整体重建

## 数据结构

`<课程名>-KA.json` 的完整数据结构见规则 `.claude/rules/ka-json-schema.md`。

核心字段：`课程名称`、`课程描述`、`知识体系`（`领域` + `知识点[]`）、`更新时间`、`完整性评分`（可选）。

## 工作流程

### 1. 解析参数

从用户输入提取：
- 课程名称（必填）
- 可选 `-autoN`（N 为最大循环次数，如 `-auto10`）

### 2. 查找课程

读取 `.harness/data/courses.json`，按「名称」精确匹配课程。
- 未找到 → 提示「课程不存在，请先用 /courses 创建」，结束

### 3. 读取现有知识体系

- 若 `.harness/data/<课程名>-KA.json` 存在 → 读取，作为丰富完善的基础
- 若不存在 → 从零生成

### 4. 生成/完善知识体系

根据课程名称、课程描述（及现有知识体系）生成二级知识体系：
- 一级：知识领域，覆盖课程的核心方向
- 二级：每个领域下的知识点

### 5. 评估稳定性（auto 模式必做）

按「稳定性评价」标准，让 LLM 输出量化指标（0–100）。

### 6. 循环（auto 模式）

重复 4–5，满足以下任一条件即结束：
- 完整性评分达到阈值（默认 90）
- 连续两次迭代知识体系无实质变化
- 达到最大循环次数 N

### 7. 保存

写入 `.harness/data/<课程名>-KA.json`，更新「更新时间」（及「完整性评分」）。

### 8. 输出

展示知识体系概览：领域数量、知识点总数、完整性评分（如已评估）。

## 知识体系约束

- 「领域」和「知识点」必须是**名词或短语**
- 不能是句子，不能带补充说明，最好不要有标点符号
- 二级结构：每个「领域」下挂若干「知识点」，知识点不跨领域重复
- 内容应贴合课程名称与课程描述，避免无关领域

## 稳定性评价

评价维度：
- 完整性：是否覆盖课程的核心知识领域
- 粒度：每个领域下的知识点是否充分、有无明显遗漏
- 稳定性：与上一次迭代相比是否有实质变化

量化指标：0–100 分。默认以 ≥ 90 视为「相对稳定」。

## 约束

- 只读写 `.harness/data/courses.json`（读）与 `.harness/data/<课程名>-KA.json`（读写），不涉及其他文件
- 文件名中的课程名与课程「名称」保持一致（中文原名）
- 时间格式统一 `yyyy-MM-dd hh:mm:ss`（24 小时制，本地时间）
