# /question-apply 应用题

生成符合排版规范的应用题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「应用题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：给出具体应用场景、数据与条件，提出需要运用所学知识/方法解决的问题，如「某系统日均请求 10 万，请用……方法估算并给出结论」，无编号、无引导
- 答案：体现「用什么知识/方法 → 如何应用 → 求解过程 → 结论」，分条列出，步骤完整可核验
- 涉及数值计算、过程推导时用 LaTeX 公式（行内 `$...$`、独立 `$$...$$`）；数据对比用标准 Markdown 表格
- 场景应真实、条件自洽，答案唯一可判，避免开放性过强
- 评分标准：在答案之后给出「评分标准」独立部分，按「方法选用、求解过程、结论」分项赋分，含满分与给分/扣分要求，用 `---` 分隔
- 难度可涉及应用、分析等较高认知目标，默认难度 4
- 需要流程、示意时生成 svg 插入，图片存入同级 `images/`，md 内以 `images/xxx.xxx` 引用，立即生成不占位
