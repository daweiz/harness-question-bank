# /question-judge 判断题

生成符合排版规范的判断题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「判断题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：一个明确的陈述句，判其对错，无编号、无引导
- 陈述应存在明确的「正确/错误」结论，避免模棱两可
- 答案为「正确」或「错误」，写入「答案」部分
- 解析：说明判断依据；判断为错误时指出正确表述
- 错误陈述宜基于常见误解（概念混淆、数值错位、程度夸大等）
- 难度贴合一至三级认知目标（识记/理解/应用），默认难度 3
- 需要图形时生成 svg 插入；公式用 LaTeX（行内 `$...$`、独立 `$$...$$`）
