# /question-multiple 多选题

生成符合排版规范的多选题。

## 排版规范

严格遵循 `.claude/rules/question-type-format.md` 中「多选题」的格式；试题文件结构与 SHA-256 去重规则见 `.claude/rules/question-file-format.md`。

## 生成要点

- 题干：明确说明选择范围（如「以下属于……的有」），无编号、无引导
- 选项：4 个（A/B/C/D），正确项至少 2 个
- 答案：给出全部正确项字母，按字母序排列（如 `ACD`）
- 解析：逐一说明每个正确项入选理由与干扰项排除理由
- 干扰项应为相近概念或常见错误，避免明显错误项
- 难度贴合一至三级认知目标（识记/理解/应用），默认难度 3
- 需要图形时生成 svg 插入；公式用 LaTeX（行内 `$...$`、独立 `$$...$$`）
