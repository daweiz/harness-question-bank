# 出题计划分配策略（/question）

从 `/question` 命令中分离出的策略性记忆，供题库建设时统一遵守。生成 9 种题型（判断/填空/单选/多选/概念/简答/设计/应用/综合）与 5 级难度（1–5）的覆盖。

**Why:** 直接给「轮换题型」的说明，难以保证按指定出题数量同时覆盖知识点、题型和难度；把算法固定成记忆，各轮、各课程行为一致。

**How to apply:**
- `-n 数量` 为本轮生成试题总数，默认 10；不指定题型/难度时，算法在全量 9 题型 × 1–5 难度中分配
- 按覆盖缺口优先取名额：P1 知识点完全未覆盖 → P2 该题型未覆盖 → P3 该难度未覆盖 → P4 已全覆盖则轮换取当前题量最少的组合；每个（知识点×题型×难度）组合每轮至多 1 题，保证覆盖广度
- 富媒体比例 `-m`（默认 30）：从名额中优先挑设计题 > 综合题 > 应用题 > 概念题，及结构图/流程图/标注图类知识点
- 相关规则见 [[question-type-format]] 与 [[question-file-format]]
