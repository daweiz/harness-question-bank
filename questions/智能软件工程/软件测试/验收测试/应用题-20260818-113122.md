某银行委托软件公司开发「公积金网上提取系统」，合同约定的验收标准为：需求规格说明书中的全部 120 项需求均需有对应的验收测试用例；验收用例执行通过率不低于 $98\%$；不允许存在 A 级（严重）缺陷，B 级缺陷不超过 3 个。验收测试小组须先针对关键输入「提取金额」字段设计验收用例，再依据验收执行结果给出验收结论。该字段输入规则为：取值区间 $[1, 50000]$ 元，只允许整数，不能为 0 或负数，也不能超过区间上限。

请完成：
1. 用等价类划分法为「提取金额」字段设计验收用例，列出有效等价类、无效等价类及其代表用例；
2. 依据下列验收执行结果，计算用例通过率与需求覆盖度，并对照合同验收标准逐项给出判定；
3. 给出最终验收结论；若结论为不通过，说明整改与再验收的流程。

验收执行结果：

| 指标 | 数值 |
|------|------|
| 设计验收用例总数 | 156 |
| 执行通过用例数 | 152 |
| 发现 A 级缺陷 | 1 |
| 发现 B 级缺陷 | 2 |
| 发现 C 级缺陷 | 1 |
| 有对应验收用例的需求项 | 118 |

---

答案：1. 方法选用。验收测试以需求规格说明与合同为验收依据，属于黑盒、用户侧验证，采用等价类划分法以最少用例覆盖输入域，并对区间边界作补充校验。

2. 等价类划分与代表用例。

| 类别 | 划分依据 | 代表用例 |
|------|----------|----------|
| 有效等价类 | 整数且在 $[1, 50000]$ 内 | 输入 100，应受理 |
| 无效等价类 1 | 0 或负数 | 输入 0、-1，应提示错误 |
| 无效等价类 2 | 超过区间上限 | 输入 50001，应提示错误 |
| 无效等价类 3 | 小数（非整数） | 输入 10.5，应提示错误 |
| 无效等价类 4 | 非数字字符 | 输入 "abc"，应提示错误 |
| 边界值校验 | 区间边界 1 与 50000 | 输入 1、50000，应受理 |

3. 指标计算。
- 用例通过率：$\dfrac{152}{156}\times 100\% \approx 97.4\%$
- 需求覆盖度：$\dfrac{118}{120}\times 100\% \approx 98.3\%$

4. 对照合同验收标准逐项判定。

| 验收标准 | 实际值 | 判定 |
|----------|--------|------|
| 全部 120 项需求均有对应验收用例 | 118 项 | 不达标 |
| 用例执行通过率 $\geq 98\%$ | $97.4\%$ | 不达标 |
| 不允许存在 A 级缺陷 | 发现 1 个 | 不达标 |
| B 级缺陷不超过 3 个 | 2 个 | 达标 |

5. 结论。三项关键标准均未满足，最终验收结论为**不通过**。整改与再验收流程：修复缺陷（先处理 A 级阻断性缺陷，再修复 B/C 级）→ 对修复内容及受影响功能执行回归测试 → 为缺失用例的 2 项需求补充验收用例并执行 → 重新组织验收测试并复算通过率与覆盖度 → 全部达标后由用户方确认签字并出具验收报告。

---

评分标准：（满分 10 分）
- 方法选用（2 分）：正确选用等价类划分法并说明验收测试的依据（需求规格说明/合同）。
- 求解过程（5 分）：等价类划分完整、代表用例合理（2 分）；通过率与需求覆盖度计算正确（2 分）；验收标准逐项对照正确（1 分）。
- 结论（3 分）：验收结论判定正确（1 分）；整改与再验收流程完整、步骤顺序合理（2 分）。

---

解析：验收测试依据需求规格说明与合同，而不是内部实现细节，属于黑盒、用户侧验证。等价类划分以最少用例覆盖全部输入域，配合边界值校验可发现区间类缺陷。通过率、需求覆盖度、缺陷等级等量化指标共同决定验收结论；A 级缺陷为阻断性缺陷，即使通过率达标也不能通过验收。该题通过率与覆盖度均低于合同标准，且存在 A 级缺陷，故验收不通过。
