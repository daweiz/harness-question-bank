GitOps 是一种将声明式基础设施与版本控制系统相结合的持续部署实践，它以 Git 仓库作为部署状态的唯一事实来源，通过自动同步机制使集群的实际状态不断收敛到仓库中声明的期望状态；当变更出现问题时，可借助 Git 版本回滚快速恢复到上一个稳定状态。

---

答案：正确

---

解析：GitOps（如 Argo CD、Flux 等工具）的核心思想是「声明式基础设施 + Git 仓库作为唯一事实来源」：应用与集群的期望状态以声明式清单形式保存在 Git 仓库，同步控制器持续比较并自动将集群实际状态拉向期望状态；由于一切变更都经过 Git 提交，部署具备版本化、可审计与可回滚的特点，出现异常时可快速回退到上一稳定版本，故题干说法正确。
