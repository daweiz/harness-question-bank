构建工具负责将源代码编译、打包为可部署产物并自动管理依赖。在 Maven 构建体系中，项目的依赖、插件与构建配置统一声明在名为 ____ 的 XML 配置文件中。

---

答案：pom.xml

---

解析：Maven 是 Java 生态中广泛使用的构建工具，其核心配置文件为 pom.xml（Project Object Model），通过其中的依赖坐标（groupId、artifactId、version）声明并管理第三方依赖，还可配置插件与构建生命周期，实现自动化构建。类似地，前端常用 npm 与 Vite，Java 新项目亦可使用 Gradle。
