关于基于大模型的 AI 代码补全工具在软件构造中的应用，下列说法正确的有（　）。

---

A. 补全工具根据光标前的代码上下文进行概率预测，逐词或逐段生成建议
B. 补全质量受训练数据覆盖度影响，在特定业务库、内部 API 上的建议可能不准确
C. 保持命名规范、注释清晰与仓库结构一致，有助于提升补全建议的可用性
D. 补全工具生成的多行代码一定符合项目编码规范，无需再人工检查调整

---

答案：ABC

---

解析：代码补全本质是基于上下文的条件式生成，A 正确；模型对训练数据覆盖不足或低频出现的 API 可能给出不准确建议，B 正确；一致、清晰的上下文能提高预测质量，C 正确；生成代码仍需人工检查是否符合规范，D 错误。
