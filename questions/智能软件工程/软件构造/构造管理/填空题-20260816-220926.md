构建产物应携带唯一的版本标识以支持可追溯管理。在语义化版本（SemVer）中，版本号格式为 X.Y.Z：X 为主版本号，Y 为____，Z 为修订号；当发布包含不兼容的 API 变更时，应递增____版本号。

---

答案：次版本号；主

---

解析：语义化版本用三段版本号传递变更意图：主版本号（X）在不兼容的 API 变更时递增，次版本号（Y）在向后兼容地新增功能时递增，修订号（Z）在向后兼容的缺陷修复时递增。统一的版本标识使构建产物可追溯、可比较，是构造管理的基础要素。
